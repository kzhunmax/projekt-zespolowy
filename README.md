# System Zarządzania Zleceniami Serwisowymi

Projekt zespołowy systemu informatycznego cz. 1, rok akademicki 2026/27.
Kompletny projekt systemu (bez implementacji) dla firmy serwisowej naprawiającej sprzęt AGD (pralki, lodówki, piekarniki) w Lublinie i okolicach.

**Cel systemu:** cyfryzacja przyjmowania, przydzielania i realizacji zleceń serwisowych, powiadomienia klientów o statusie, płatność online i raporty dla właściciela.
